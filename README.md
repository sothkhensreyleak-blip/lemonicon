# CrownIcon Plugin
**Author:** `*crownixed៚`

## របៀប Build ទៅជា `.jar`
1. បង្កើត Repository ថ្មីលើ **GitHub** រួច Upload folder ទាំងមូលនេះចូលទៅ។
2. ចូលទៅកាន់ tab **Actions** លើ GitHub -> ចុច **Build CrownIcon JAR** -> **Run workflow**។
3. ទាញយកឯកសារ `CrownIcon-1.0.0.jar` ពី **Artifacts** រួចដាក់ចូល folder `plugins/` នៃ Server របស់អ្នក (ត្រូវមាន `PlaceholderAPI` ផង)។

## បញ្ជី Placeholder ទាំង ២៤ មុខ (សម្រាប់ដាក់ក្នុង TAB / Scoreboard)
